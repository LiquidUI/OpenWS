<h1>Liquid UI Platform</h1>

<p><strong>Liquid UI Platform</strong> is a unified solution that simplifies, customizes, and mobilizes SAP. It brings together multiple technologies and approaches into one extensible platform, ensuring enterprises can streamline SAP without costly rebuilds.</p>

---

<h2>Product Structure</h2>

<p>The OpenWS project is now covering <strong>two key project tracks</strong>:</p>

<h3>1. WebScript Implementations</h3>
<ul>
  <li>A library of SAP simplifications and process demos.</li>
  <li>Implemented with <strong>WebScript</strong>, a JavaScript-based language that optimizes SAP transactions.</li>
  <li>Designed to be scalable, memory safe, and portable across devices.</li>
  <li>Simplifications and SDK demos are now consolidated here for easier maintenance and broader compatibility.</li>
  <li>To try any of these, you will need <a href = "https://liquid-ui.com/products/liquid_ui_sapgui.php">Liquid UI for SAP GUI</a> (core of the Liquid UI Platform).</li>
  <li>If you are interested in a trial version, please call <strong>+1.650.341.3310</strong> or email <strong>rfi@guixt.com</strong>.</li>
</ul>

<h3>2. Android Client Extensions</h3>
<ul>
  <li>Android-specific modules that extend the platform when device-native functionality is required.</li>
  <li>Complements WebScript implementations by providing local, client-side integrations.</li>
  <li>Over time, extensions will be progressively added to leverage device hardware extensively.</li>
  <li>To try any of these, you will need <a href="https://play.google.com/store/apps/details?id=com.guixt.liquidui.android&hl=en_US" target="_blank">Liquid UI Client for SAP</a></li>
</ul>
